# My To-Do List

A beginner-friendly task manager made with **HTML, CSS and JavaScript**.

## Features
- Add tasks
- Mark tasks as complete
- Delete individual tasks
- Clear all tasks
- Responsive layout for mobile and desktop

## Run locally
1. Download or extract this project.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload these project files to the repository's main branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages section.
